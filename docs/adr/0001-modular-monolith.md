# ADR 0001: Модульный монолит и ports/adapters

- Статус: accepted
- Дата: 2026-11-03

## Контекст

Нужно менять TikTok downloaders, OCR/ASR, LLM и wiki engines независимо, но система пока маленькая и не имеет доказанной потребности в распределённой инфраструктуре.

## Решение

Python modular monolith. Domain не зависит от инфраструктуры; application определяет порты; конкретные адаптеры подключаются снаружи. Ресурсоёмкие workers могут быть вынесены позже по тем же контрактам.

## Последствия

Плюсы: локальная разработка, транзакционная простота, мало operational overhead, заменяемые адаптеры. Минусы: нужно дисциплинировать границы модулей; architecture fitness tests обязательны. Микросервисы и message broker не вводятся «на вырост».
